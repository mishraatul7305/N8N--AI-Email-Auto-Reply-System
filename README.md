🚀 AI Email Auto-Reply System using n8n

This workflow automatically:
- Detects incoming emails using Gmail Trigger
- Filters messages based on conditions
- Generates smart replies using LLM (OpenRouter)
- Sends automated responses via Gmail

✨ Features:
- AI-powered email responses
- Spam filtering
- Memory-enabled conversations
- Optional WhatsApp notifications

🛠 Built with:
- n8n
- Gmail API
- OpenRouter AI
